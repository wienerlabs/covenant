# Third-party license inventory (C-107)

Covenant is licensed under **LGPL-2.1** (see [`LICENSE`](../LICENSE)). This file
inventories the licenses of our **direct** third-party dependencies so we can
confirm they are compatible with shipping under LGPL-2.1, and so any license
that needs a human decision is tracked rather than forgotten.

- **npm** (web app + SDK): generated by
  [`app/scripts/license-inventory.ts`](../app/scripts/license-inventory.ts).
  CI runs it with `--check` and fails on any **unknown / unassessed** runtime
  license. Regenerate this table with:
  ```bash
  cd app && npx tsx scripts/license-inventory.ts
  ```
- **Cargo** (Anchor program): `anchor-lang` / `anchor-spl` `0.30.1` and the
  whole `anchor-*` tree are **Apache-2.0** (verified via `cargo metadata`).
  `solana-program` and the SPL crates are Apache-2.0 as well.

## ⚠️ Requires legal review before mainnet

- **`@walletconnect/universal-provider`** — ships under Reown's custom
  **"WalletConnect Community License"** (non-OSI; see the package's `LICENSE.md`),
  not a standard permissive license. It is a runtime dependency (wallet
  connection). **Legal must confirm** its redistribution terms are compatible
  with distributing Covenant under LGPL-2.1 before mainnet launch, or the
  dependency must be replaced/removed. Tracked here and in the `--check` gate
  (which warns but does not block, since the dependency is deliberate).

## LGPL-2.1 compliance notes

- **Permissive deps** (MIT / Apache-2.0 / ISC / BSD / Unlicense) impose no
  copyleft on Covenant and may be combined freely under LGPL-2.1.
- **Our own code** is LGPL-2.1: recipients of a distributed build are entitled
  to the corresponding source for the LGPL-covered portions and may relink
  against modified versions. Keeping the public repository as the source of
  truth satisfies this for our open distribution.
- **The flagged WalletConnect license** is the one item that the permissive
  analysis above does *not* cover — resolve it before any mainnet/production
  distribution (see the review section).
